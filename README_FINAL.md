# PAIMANA SIH 26103 — Corrected Final Prototype

This package is the corrected version of the audited prototype. It keeps the core idea — official PAIMANA data → monitoring features → explainable risk — while fixing the main methodological problems found in the original implementation.

## What was fixed

1. **Target leakage removed:** historical agency/sector/ministry performance uses only snapshots strictly earlier than the current snapshot.
2. **Correct planned duration:** `target DoC - start date`, with `approval_to_start_months` retained separately.
3. **Censored time labels handled:** projects whose target date has passed but have no revised DoC are not falsely labelled as on-time.
4. **Temporal validation:** the latest available monthly snapshot is held out as the test month; earlier snapshots are training data.
5. **Monitoring features added:** project age, expenditure ratio, progress/expenditure divergence, month-over-month progress velocity and expenditure velocity.
6. **Historical comparables fixed:** comparable projects must come from an earlier snapshot.
7. **Portable paths:** scripts use paths relative to the project instead of `/home/claude` or `/mnt/user-data`.

## Run

```bash
pip install -r requirements.txt
python run_pipeline.py
```

The pipeline expects `data/paimana_projects_apr_jul_2026.csv` to exist.

Outputs:
- `data/snapshot_features.csv`
- `backend/models/cost_monitor.joblib`
- `backend/models/time_monitor.joblib`
- `results/cost_monitor_metrics.json`
- `results/time_monitor_metrics.json`
- `results/historical_comparables.csv`
- `results/risk_profiles.json`
- `results/top10_risk_projects.csv`

## Important SIH claim

Do **not** present the old AUC 0.81 / 0.94 figures as final validated performance. They came from an evaluation setup affected by target leakage and a flawed time label. The new metrics should be generated by `run_pipeline.py` and reported with the test month, sample size, ROC-AUC, PR-AUC, F1, precision, recall and Brier score.

## Current limitation

Only April–July 2026 snapshots are available in this package. Four monthly snapshots are enough to demonstrate temporal monitoring, but not enough to claim production-grade long-horizon forecasting. For the SIH presentation, describe this as a working temporal monitoring prototype and state that additional historical PAIMANA snapshots would strengthen model training and validation.
